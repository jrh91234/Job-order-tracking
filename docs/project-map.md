# Project Map (Token-Saving Guide)

This file is a lightweight index so agents do not need to scan the whole repository.
Update this file whenever a new major folder or service is added.

## How to use
- Start here before opening code files.
- Read only the folder(s) related to the task.
- If ownership is unclear, ask one clarifying question before broad exploration.

## Areas
- `docs/`: operational docs and agent guidance.

## Task routing checklist
1. Identify feature/bug domain from user request.
2. Map request to exactly one primary folder.
3. Open the minimum set of files needed.
4. If blocked, ask for path hints instead of expanding scope broadly.
